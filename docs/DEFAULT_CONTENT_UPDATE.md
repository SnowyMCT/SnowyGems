## 远征符文

| 系列 | 等级 | 效果与适用装备 |
| --- | --- | --- |
| 星锋 | I / II | 剑的主手攻击力 +1 / +2 |
| 磐岩 | I / II | 对应盔甲槽位护甲 +1 / +2 |
| 生息 | I / II | 对应盔甲槽位生命上限 +2 / +4 点 |
| 轻捷 | I / II | 靴子移动速度属性 +0.01 / +0.02，不是百分比 |
| 矿脉 | I / II | 主手持镐续加急迫 I / II |
| 疾行 | I / II | 主手持剑潜行右键：速度 I / II，5 秒，冷却 12 秒 |
| 夜航 | 单级 | 佩戴头盔续加夜视 |
| 潮息 | 单级 | 佩戴头盔续加水下呼吸 |
| 净毒 | 单级 | 主手持剑潜行右键清除中毒，成功后冷却 10 秒 |
| 轻羽 | 单级 | 主手持剑潜行右键获得 6 秒缓降，冷却 16 秒 |

实际 ID 为 `远征星锋符文I`、`远征星锋符文II` 等；单级为 `远征夜航符文` 等。每件装备同 ID 最多一颗，同系 I/II 互斥。疾行、净毒、轻羽还共用主动符文互斥组，避免同一次潜行右键触发多个主动符文。互斥只限制同件装备，不限制其他装备。

矿脉与疾行分别让两个等级共用一个技能 ID，从固定 Lore 数字读取等级；更换疾行 I/II 的剑不会刷新同技能冷却。新标记使用“远征/…”文本，不匹配旧默认技能。卸下装备只停止续加，已施加药水效果等待自然到期（夜视最多约 12 秒，其余定时效果约 5 秒）。

### 锻造、升级与回收

新符文在 `/sgem rune` 合成，在 `/sgem embed` 镶嵌。旧颜色符文台按旧分类匹配，不要求服主改写旧 GUI 来容纳新符文。

- 基础 I 级：24 远征符砂；回收获得 8 符砂。
- II 级：3 颗同系 I 级 + 16 符砂；回收获得 24 符砂。
- 单级夜航/潮息/净毒/轻羽：32 符砂；回收获得 10 符砂。
- 远征符文匣：右键等概率发放六种 I 级符文之一，不直接强化装备。

升级和回收只消耗背包中未镶嵌的符文物品，不修改装备上已有的等级。要换 II 级，需要先按原拆卸规则移除 I 级，再镶 II 级；费用、损坏概率和撤销冲突仍受服务器设置约束。

符砂使用独立材料 ID，不自动兑换旧“符文碎片”，避免改变现有商店和回收经济。插件不会自动给玩家发放材料，服主可将以下命令接入商店、任务或活动（将玩家名替换成实际名字）：

```text
/sgem give 玩家名 远征符砂 128
/sgem give 玩家名 远征符文匣 1
/sgem give 玩家名 匠心轻落宝石 1
/sgem give 玩家名 远征疾行符文I 1
```

## 配方文件与停用方式

仍先加载 `runes/forge.yml`，再按文件名加载 `runes/packs/` 第一层的 `.yml` / `.yaml`。不会加载 runes 根目录中以前被忽略的其他草稿文件，不递归加载更深层目录。同 ID 配方不能覆盖：冲突或引用缺失会拒绝此次重载并保留旧注册表。

停用新锻造内容可将 `runes/packs/expedition.yml` 顶层 `Enabled` 改成 false。单项配方也支持 `Enabled: false`。这样保留宝石和技能定义，已发放物品仍能被识别；已有物品仍可通过管理员发放或使用。不要通过删除 ID 停用内容，否则旧物品可能失去定义；直接删除默认文件也会在下次加载时补回。

## 更新与验收

1. 备份原 JAR、插件目录和世界/玩家物品数据；先在测试服进行。
2. 正常停服并替换 JAR，保留原数据目录。不要只执行 reload 来更新程序。
3. 启动后确认四个新增文件已释放，`/sgem compat all` 无新配置错误。
4. 用旧装备、旧技能和旧符文配方回归，确认原有 ID、标记和效果仍可识别。
5. 发放符砂，测试合成、升级、回收以及满背包/缺料不扣材料。
6. 测试新符文同系互斥、主动互斥、技能槽位和跨等级冷却；测试不支持现代属性的服务端能正常加载其余内容。
7. 先镶夜航再镶隐技粉尘，确认隐藏后仍生效；先拆粉尘再拆夜航。

本次自动检查确认旧 YAML 值不变、新 ID 无冲突、配方引用完整、新技能标记不触发旧默认技能；构建与 44 项单元测试通过。配方文件合并测试使用注入的数据读取器，服务器中的 TabooLib YAML 解析和真实背包交互仍需以上实服验收。
