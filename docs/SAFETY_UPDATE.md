# 安全修复与功能说明

本次基于工作区现有 0.0.6 修改，保留原有属性合并与版本调整。未自动安装到运行中的服务器。

## 镶嵌限制

在现有宝石节点内添加：

```yaml
我的攻击宝石:
  Name: 我的攻击宝石
  Material: DIAMOND
  Require: [WEAPON]
  Embed: 2
  ExclusiveGroup: attack-style
  Rewards:
    - Attribute{name=attack_damage;operation=0;slot=auto;var=v+1;limit=2}
```

`Embed` 是单件装备上同 ID 已记录镶嵌次数的上限，0 表示不限制。互斥组禁止不同 ID 同组共存，同 ID 重复仍由 Embed 控制。预览和确认共用规则，批量镶嵌逐颗重新验证。

`TrackApplied: false` 表示使用后不记录可拆卸实例，适合修复石等一次性物品。不要把它用于依赖镶嵌次数/互斥组的宝石：这些限制统计的是已记录实例。纯不可撤销效果即使未配置此字段，也不会生成新的可拆卸记录。

## 拆卸和隐藏

- 新的无限耐久、ItemFlag、SkillToNBT 保存撤销凭据，拆卸时撤销本次变化。
- 每一条已执行奖励都必须支持且成功完成撤销，才移除实例并进入返还判定。
- 混合了金币、修复等不可撤销效果的记录不能返还。旧记录缺少必要凭据也会拒绝拆卸，失败费用按现有退款机制退回；退款失败记录在日志中。
- 技能隐藏不再禁用技能。隐藏期间先拆粉尘，再镶嵌或拆卸其他宝石，避免恢复已被改动的技能文本。
- Lore 恢复是局部恢复；隐藏文本会追加回可见说明，不保证恢复原行位置。外部插件改动导致冲突时不强行覆盖。

## 技能执行

- 主动/定时技能共用按玩家和技能 ID 的冷却；至少一条技能效果成功后进入冷却。成功安排 Delay/Repeat 任务也算施放成功。
- 定时技能按主手、副手、头、胸、腿、脚顺序检查，同 ID 每轮至多成功施放一次；不会自动选择等级最高的装备。
- `Slot: [head, chest]` 可限制定时技能来源；主动交互技能目前以主手为入口。
- 潜行左键同一服务器 tick 去重；发射物缺失原物品快照时不借用当前主手技能。
- 发射物通用和专用触发合并为一次施放，一行匹配多个触发标记时只执行一次。
- 每次施放共享最多 256 次函数分派、16 层嵌套、128 个延迟任务；延迟任务重载后失效，玩家离线/死亡或目标无效时不执行。

## 图鉴与操作日志

- `/sgem catalog`：只读图鉴，显示适用范围、成功率、同类数量上限、互斥组及拆卸说明，权限 `snowygems.catalog`。
- `/sgem history <玩家名>`：显示本次启动以来全局最近 500 条缓存中的该玩家最近 5 条，权限 `snowygems.history`。不自动执行补偿。
- 持久日志：插件目录 `logs/operations-*.log`，5 个轮换文件，每个约 1 MiB。日志包含时间、UUID、玩家名、操作类型和结果，独立于 Debug。
- 日志用于排查与人工核对，不是崩溃恢复事务日志，也不包含完整物品备份；正常关闭时释放文件。

## 配置与点券

配置加载使用临时注册表，重复 ID、加载错误和关键引用错误会拒绝此次更新，恢复此前宝石、菜单、技能、配方和功能模块状态。strict 对配置错误拒绝加载；服务端版本不支持的功能仍按版本兼容规则处理。

首次启动没有可回退配置，加载失败会报错并停用插件；应修正后重新启用。语言、调试等全局设置不属于注册表回退范围。主动删除一个仍在装备中使用的宝石 ID，仍会使该宝石无法正常返还；请先迁移旧装备。

明确配置 PlayerPoints 后，不可用时暂停交易，不再写入 Internal。内置点券仍使用同步 YAML 存储，未改成数据库。

## 验证范围与升级

运行 `gradlew.bat build --offline`；单元测试包含元数据接口替身，不启动真实服务端。真实 Vault/PlayerPoints、背包事件、旧物品与不同服务端版本仍须按 VERIFICATION.md 验收。

默认配置不会覆盖已有服务器文件。新增语言节点由现有迁移机制补充；新配置字段可按需手动加入。此次未添加邮件仓库、自动补偿、保底、保护石或完整属性数值模拟预览。

多条奖励仍是顺序执行，并非跨外部插件的原子事务；金币、命令、物品已发出后无法通用回滚。复杂合成应使用现有 RuneForge 规划流程。


## 图鉴与历史显示修正

- 图鉴与管理员浏览页一致：存在 Texture 时使用 PLAYER_HEAD 并加载自定义纹理，同时保留 Glow。
- 聊天历史只显示最近 5 条，最新在前；每条包含服务器本地时间、操作、物品名称、结果。
- 不再显示 UUID、原始键值、制表符和扣费中间记录；物品名称去除颜色/混淆代码、控制字符并限制长度。完整诊断日志保持不变。
- 新增聊天语言节点会随语言文件迁移补充。更换 JAR 后正常重启服务器，再测试自定义头颅及新产生的历史记录。
